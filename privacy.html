Privacy Policy: Nusta Curiosity publishing tool

Last updated: 9 November 2026

"nusta-curiosity" is a private tool used only by the owner of the Nusta Curiosity YouTube channel. It is not offered to the public.

Use of YouTube API Services

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy: https://policies.google.com/privacy

What information we access, collect and use

When the channel owner signs in with Google (OAuth 2.0) and grants permission, the tool accesses only the owner's own YouTube channel to:

  • upload and schedule the channel's own videos, and set their titles, descriptions, tags, thumbnails and caption tracks;
  • list and update the channel's own videos;
  • read comments on the channel's own videos and post replies that the owner has approved;
  • read the channel's own YouTube Analytics reports (views, watch time, audience retention).

It does not access any other user's account or channel data.

How we store and share information

The OAuth access/refresh token and the API data above are stored only on the channel owner's own computer. We do not sell, share or disclose this information to any third party, and we do not use it for advertising. We do not use cookies or tracking technologies, and we do not place any on users' devices.

Data retention and deletion

  • API data (for example video titles and comment text) is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
  • You can revoke this tool's access to your data at any time through the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the stored token stops working and is deleted, and all stored API data is deleted within 7 days.
  • You can also ask us to delete stored data at any time by contacting us (below); we delete it within 7 days.
